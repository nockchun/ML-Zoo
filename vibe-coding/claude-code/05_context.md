# Context 이해하기

## 기능이 늘어나면서 **컨텍스트가 어떻게 차는지** 체감한다.

현재 context를 확인.
```prompt
/context
```

```prompt
[목표]
메뉴 옵션 기능을 만들어 주세요.

[요구사항]
- 메뉴를 클릭하면 바로 담기는 대신 옵션 선택 창이 뜬다.
- 옵션: 온도(Hot/Ice), 샷 추가(0~3), 사이즈(Regular/Large)
- 가격: 샷당 +500, Large +700, Ice +0
- 옵션 창에 실시간 예상 금액 표시
- [담기] 누르면 장바구니에 추가, [취소] 누르면 닫힘

[비즈니스 규칙 - 반드시 지킬 것]
- 자몽에이드는 Hot 선택 불가 (Ice만)
- 자몽에이드는 샷 추가 불가
- 같은 메뉴라도 옵션이 다르면 장바구니에서 별도 줄로 관리한다
  예: 아메리카노(Hot/샷0/R) 과 아메리카노(Ice/샷1/L) 은 다른 줄

[설계 제약]
- 옵션 가격 계산은 src/cart.js 의 순수 함수로. DOM 접근 금지
- 옵션 창 UI 는 src/app.js 에서만
- 장바구니 항목 식별 키는 메뉴ID + 옵션 조합으로 만든다

[금지]
- 쿠폰, 재고, 저장 기능 (아직 아님)
- 새 라이브러리

[개발환경]
conda 환경에 vscode가 있습니다. 개발 및 테스트는 모두 여기서 이루어 져야 합니다.

[테스트]
chrome extension을 이용하여 실제 브라우저에서 동작을 테스트 해 주세요.
```

완료된 코드를 저장.
```bash
git save "feat: 옵션 선택 (온도/샷/사이즈)"
```

개발후 context를 확인.
```command
/context
/context all
```

---
## `/compact`와 `/clear` 의 차이를 안다

```prompt
/compact 파일 구조, 순수 함수 분리 원칙, 비즈니스 규칙, 남은 TODO만 남기고 압축해줘
```
압축 후 context를 확인.
```command
/context
```

압축이 **무엇을 지우고 무엇을 남기는지** 확인해 봅니다.
```prompt
질문 3개에 짧게 답해 주세요.
1. cart.js 에 절대 넣으면 안 되는 것은?
2. 자몽에이드에 적용되는 특수 규칙 2가지는?
3. 같은 메뉴 다른 옵션은 장바구니에서 어떻게 처리하기로 했었나요?
```

## 터미널 환경 설정 및 기능 팁.

압축 설정 방법
```prompt
/autocompact
/autocompact 500k
/autocompact auto
```

상태 표시줄에 컨텍스트 사용률을 상시 표시
```prompt
/statusline 컨텍스트 사용률과 현재 git 브랜치, 세션 이름을 상태줄에 표시해줘
```
이 프롬프트 이후에 claude를 나갔다가 다시 들어 옵니다.

화면을 간결하게 (toggle 기능)
```prompt
/focus
```

마지막 응답을 클립보드로.
```prompt
/copy
```

"배운 것을 뽑아내라"고 했죠. `/export` 가 그 자동화 버전입니다.
다만 전체를 다 저장하면 나중에 읽기 힘드니, **핵심만 직접 정리하는 습관**이 여전히 낫습니다.
```prompt
/export work1.txt
```
