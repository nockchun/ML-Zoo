# 무너뜨리고 다시 세우는 과정

## 장바구니 만들기

**프롬프트**
```prompt
[목표]
장바구니 기능을 만들어줘.

[요구사항]
- 메뉴 카드를 클릭하면 장바구니에 담긴다
- 이미 담긴 메뉴를 또 클릭하면 수량이 1 증가한다
- 장바구니에 각 항목의 이름, 수량, 소계(가격×수량)를 표시
- 수량 +/- 버튼으로 변경, 0이 되면 항목 삭제
- 삭제 버튼(×)도 별도로 제공
- 하단에 전체 합계 표시

[설계 제약 — 반드시 지킬 것]
- src/cart.js 를 새로 만들고, 여기에는 **순수 함수만** 넣는다
  - DOM 접근 금지 (document, window 사용 금지)
  - localStorage 접근 금지
  - 같은 입력이면 항상 같은 출력
- 화면 갱신과 이벤트 처리는 src/app.js 에서만
- cart.js 가 제공할 함수:
  addItem(cart, menuItem) -> 새 cart
  changeQty(cart, itemId, delta) -> 새 cart
  removeItem(cart, itemId) -> 새 cart
  getTotal(cart) -> 정수
- 원본 cart 를 변형하지 말고 항상 새 객체를 반환한다

[금지]
- 프레임워크, npm 패키지
- 옵션·쿠폰·저장 기능 (아직 아님)

[개발환경]
conda 환경에 vscode가 있습니다. 개발 및 테스트는 모두 여기서 이루어 져야 합니다.

[테스트]
chrome extension을 이용하여 실제 브라우저에서 동작을 테스트 해 주세요.

작업 후 브라우저에서 무엇을 확인하면 되는지 알려줘.
```

"python -m http.server 8989"로 서버를 실행하여 기능 확인.
정상적으로 개발이 되었으면 커밋. 오류가 있으면 추가 수정프롬프트로 수정 후 커밋.
```bash
git save "feat: F2 장바구니와 합계"
```

## /rewind

**프롬프트** : 엉망으로 만들기
```prompt
bash 명령을 써서 src/ 안의 모든 .js 파일 맨 위에 "// TEMP MARKER" 주석 줄을 추가해 주세요.
Edit 도구 말고 반드시 sed 같은 bash 명령을 써 주세요.
readme.md를 만들어 프로젝트를 설명, 정리해 주세요.
```

/rewind 후 "Restore code and conversation" 선택
```command
/rewind
```
소스코드에서 돌아가지 않은 파일 확인후 undo 수행
```bash
git undof
```

## rule of three

- **누더기 대화**가 어떻게 만들어지는지 직접 겪는다

이제 아래를 **순서대로** 보냅니다. 중간에 바로잡으려 하지 말고 그냥 진행하세요.

```prompt
장바구니 항목 표시 방식을 바꿔줘.
```

```prompt
아니 그거 말고 좀 더 컴팩트하게.
```

```prompt
음 그것도 아니야. 수량은 좀 더 크게 보였으면 좋겠어.
```

```prompt
아까 처음 거가 나았던 것 같아. 근데 삭제 버튼은 오른쪽으로.
```

```prompt
이제 화면이 깨지네. 고쳐줘.
```

### 가장 중요한 기술 : 4단계

##### step 1. 배운 것부터 뽑아낸다 (코드를 버리기 전에!)
```prompt
지금까지 장바구니 표시 방식을 여러 번 바꾸면서 시도한 내용을 정리해줘.
- 시도한 레이아웃들과 각각의 문제점
- 화면이 깨진 원인
- 다시 만든다면 처음부터 정해두어야 할 결정 사항 (구체적인 수치로)

코드는 건드리지 말고 정리만 해줘.
```

이 답을 **터미널 밖 메모장에 복사해 두세요.** 다음 프롬프트의 재료입니다.

##### step 2. 코드를 버린다
```bash
git undof
git s
```

##### step 3. 대화도 버린다
`/clear` 는 컨텍스트를 완전히 비웁니다. 인자로 이름을 주면 이전 대화가 `/resume` 피커에서 그 이름으로 남습니다.
```prompt
/clear 장바구니-레이아웃-실패한-시도
```

##### step 4. 배운 것을 넣어 한 번에 다시 시킨다

step 1에서 복사해 둔 내용을 붙여 넣고 아래처럼 구성합니다

```prompt
장바구니 항목의 표시 방식을 확정하려고 한다.

[결정 사항 - 확정이니 묻지 말고 따라주세요]
- 한 항목은 한 줄. 높이 56px 고정
- 왼쪽부터: 메뉴명 / 수량 컨트롤 / 소계 / 삭제 버튼(×)
- 수량 컨트롤은 [−] [숫자] [+] 형태. 숫자는 16px, 최소 폭 24px
- 소계는 오른쪽 정렬, 천단위 콤마
- 삭제 버튼은 맨 오른쪽 고정

[이전 시도에서 겪은 문제 - 반복하지 않도록 심도깊게 검토해 주세요]
(여기에 step 1에서 정리한 내용 붙여넣기)

[제약]
- styles.css 와 src/app.js 두 파일만 수정
- 기존 CSS 를 재작성하지 말고 장바구니 관련 규칙만 교체
- cart.js 는 절대 건드리지 마

[개발환경]
conda 환경에 vscode가 있습니다. 개발 및 테스트는 모두 여기서 이루어 져야 합니다.

[테스트]
chrome extension을 이용하여 실제 브라우저에서 동작을 테스트 해 주세요.

구현이 완료되면 브라우저에서 확인할 항목을 알려주세요.
```

개발이 정상적으로 되었으면 git commit.

```bash
git save "feat: 장바구니 레이아웃 확정"
```

2개의 구현 차이를 비교하고 추천 방법을 질문.
```prompt
try/grid 브랜치와 try/flex 브랜치의 구현을 비교해 주세요.

git diff 로 둘 다 확인하고,
- 코드 길이
- 반응형 대응 난이도 (나중에 모바일 대응을 할 예정)
- 메뉴 개수가 바뀔 때의 안정성

세 관점에서 표로 정리하고 추천을 알려 주세요.
```

분석/추천 내용확인 후 최종 판단.
```bash
git sw main
git mg try/grid          # 고른 쪽
git delf try/flex      # 버릴 쪽
git l
```
