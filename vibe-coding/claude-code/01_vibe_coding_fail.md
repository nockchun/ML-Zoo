# Vibe Coding 실패하는 이유 이해하기.
전통적 코딩을 그대로 따라하는 실패하는 방법 실습과 문제점 이해해 보기.

## 왜 프롬프트를 길고 구체적으로 써야 하는지를 말이 아니라 결과로 본다.
```prompt
[목표]
카페 키오스크 만들어주세요.

[개발환경]
conda 환경에 vscode가 있습니다. 개발 및 테스트는 모두 여기서 이루어 져야 합니다.

[테스트]
chrome extension을 이용하여 실제 브라우저에서 동작을 테스트 해 주세요.
```

## 코드를 쓰기 전에 질문 시키기
```prompt
[목표]
브라우저에서 동작하는 카페 주문 키오스크를 만들려고 합니다.
코드는 아직 쓰지 말고, 요구사항이 충분이 정리되고 난다음 코드를 작성해달라고 요구하면 그때 개발해 주세요.

[확정된 것]
- HTML + CSS + 순수 JavaScript만. 프레임워크·빌드도구·npm 패키지 금지
- 메뉴 6개: 아메리카노 3000, 카페라떼 3800, 바닐라라떼 4300,
  콜드브루 4000, 자몽에이드 4800, 딸기라떼 5000
- 카테고리는 커피 / 논커피 두 개
- 금액은 정수 원 단위

이걸 만들 때 내가 결정해줘야 할 애매한 지점을
질문 형태로 최대 7개 정리해줘.
각 질문마다 네가 추천하는 기본값도 함께 제시해줘.
```

결과가 나온 이후에 프롬프트 예제.
```prompt
모두 추천한대로 할게요. 아직 개발은 하지 말고 추가적으로 더 결정해야할 사항은 없나요?
```

```prompt
[개발환경]
conda 환경에 vscode가 있습니다. 개발 및 테스트는 모두 여기서 이루어 져야 합니다.

[테스트]
chrome extension을 이용하여 실제 브라우저에서 동작을 테스트 해 주세요.

네 지금까지 정리된 내요으로 개발을 진행해 주세요.
```
